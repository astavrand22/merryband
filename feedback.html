Build it with us

Keys Out lives on GitHub. If you code, draw or write, you can propose a change directly.

  1. Read the contributing guide.
  2. Fork astavrand22/merryband and make your change. Most tuning lives in the CONFIG block of index.html.
  3. Open a pull request. We review everything before it goes live.

Please keep it about the game. Don't include anyone's real name or personal story in a public post.
